# Changelog

## 0.8.0 — Phase 8: Godot editor beta

- Six named world slots with validated labels, dates, world summaries, and explicit previous-version loading.
- Validated temporary writes, retained good backups, automatic recovery, and autosave preservation before loading another world. New worlds reset the quick-save target.
- Persistent volume, larger reading text, contrast, motion, focus-pause, and frame-limit settings; audible original ambience and interaction cues.
- Terrain split into 54 reusable textures, visual-signature invalidation across coast seams, and a four-chunk runtime rebuild budget. Tool rings remain capped at 64.
- Focus/suspend audio handling, pause/resume without accumulated catch-up, and visible desktop save-failure handling before quit.
- Genuine Phase 7 compatibility fixture, save/settings/render tests, native beta UI tests, and a GitHub-to-Godot testing guide.
- World schema remains v7; preferences use their own v1 format. Project version 0.8.0 / future Android preset code 8.
- Source-only delivery for Godot testing. APK/AAB builds and device certification are deferred at the user's request.

## 0.7.0 — Phase 7: Society and memory

- Separate stable culture, clan, language, and hearth-faith identities, learned household inheritance, and remembered affiliations.
- Real harvests/construction teach crop rotation and masonry; nearby peaceful communities share knowledge faster with a common language.
- Sustained local residence can change culture, faith, and language without rewriting clan or ancestry; colony travelers carry their traditions.
- Clan solidarity adds yearly loyalty, communal faith improves recovery, and two explicit laws pause social effects or exchange.
- Live Society People/Knowledge/History/Discoveries pages, linked family browser, ruler timelines, culture/type/year/kingdom history filters, and annual resource graphs.
- Four persistent discovery emblems, original woven SVG art, and phone/desktop captures.
- Schema v7 with all genuine v1–v6 migrations, bounded histories, invalid-reference rejection, and exact continuation.
- Version 0.7.0 / Android code 7; native mobile exports and hardware acceptance remain outstanding.
